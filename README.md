# Match the Shirt — Precision Academy

Original game created, designed and developed by **Cornelius Aurelius**. Official creator website: https://corneliusaurelius.com/

## Gameplay

Match an exact football shirt. Compare the number, pattern, badge, badge position, collar and sleeve marks, not just the colour. Correct answers move to the next question automatically; wrong answers show the corrected shirt before advancing.

Modes: 30-level Campaign (three lives and a finish), 90-second Sprint (highest score) and free Practice (no pressure). Keys 1–6 select shirts; H gives a hint; Escape pauses. The game is a free original educational activity and not a colour-vision test.
